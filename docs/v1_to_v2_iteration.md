# Synapse Prompt 迭代:V1 → V2 的产品决策

## 起点(基线评估)
- 50 题评估,总分 0.818
- 发现 Pattern Bad Case:cross_paper 0.665(其他类 0.85+)

## 诊断(数据驱动)
- 抽样 eval_040(最低分)+ eval_034(最高分)
- 验证 3 个根因:
  1. 检索垄断(top 5 被一篇论文占 4/5)
  2. Prompt 没引导"跨论文综合"
  3. Recall@5 指标假阳性

## V1 Prompt(2026-05-30 上午)
- 加 "跨论文场景指引":片段不全时部分回答 + 标注未覆盖
- 结果:cross_paper 0.665 → 0.707(+6.3%)
- **副作用:out_of_scope 0.830 → 0.793(-4.5%)**

## V1 副作用的 3 个题
- eval_044:BERT vs Transformer 题,基于 Transformer 论文里一句话脑补 BERT
- eval_048:训练成本(美元),用 FLOPs 数字假装回答
- eval_049:ReAct vs CoT,展开 CoT 论文内容(论文不在库)

## V2 Prompt(2026-05-30 下午)
加 3 条"特别警告":
1. 对比类问题:必须双方都有实质内容
2. 数字/单位:必须精确匹配类别
3. 时序边界:论文发表后的概念不能基于"已知"答

## V2 预期结果
- cross_paper 保持 0.70+
- out_of_scope 回到 0.82+
- 总分 0.84+

## PM 决策反思
- **不接受"假 trade-off"** — V1 看起来是必然代价,V2 证明可消除
- **Prompt 不是一次到位,是 V1 → V2 → V3** — 分层迭代
- **"高质量拒答"是产品的高级能力** — 不是不答,是说清边界
